# TraderBot Tools — Crypto Agent

Your profile `token` is injected host-side by the TraderBot Token Injector plugin. The `token` parameter remains in the tool schema, but you do not provide it yourself.

## Currently Available Tools

### `traderbot__health`

Combined service health check.

### `traderbot__auth_check`

Validate the profile token and report its access context.

### `traderbot__profile_list`

List profiles and their modes.

### `traderbot__market_edge`

Current stub: returns `status: stub` and does not compute market edge yet.

### `traderbot__market_prices`

Return market prices from the live WebSocket cache.

## Planned Tools

No planned tools are available through this workspace.
