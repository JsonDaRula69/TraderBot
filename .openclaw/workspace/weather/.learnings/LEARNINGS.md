# LEARNINGS.md

_Market patterns discovered through trading. One entry per pattern. Recurrence-Count increments when the same pattern is observed again._

## Template

```markdown
## YYYY-MM-DD: [Brief Pattern Name]

- **Category**: Weather
- **Subcategory**: TEMPERATURE | PRECIPITATION | HURRICANE | INDEX
- **Pattern**: What I observed
- **Evidence**: Win rate / edge observed across N instances
- **Conditions**: When does this hold? (timeframe, region, model, thresholds)
- **Recurrence-Count**: 1
- **Recurrence-History**: YYYY-MM-DD (first observed)
- **Status**: ACTIVE | PENDING_REVIEW | VALIDATED | DEPLOYED | SUPERSEDED
```
